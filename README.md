Ahmed's Portfolio App
A clean, personal, and interactive Flutter-based portfolio app designed to elegantly showcase a designer or developer's profile. With a user-friendly layout, interactive elements, and essential contact details, it offers a comfortable and engaging user experience.
✨ Highlights

📸 Interactive Profile Image: Tap to switch the profile picture, making a strong first impression with dynamic visuals.  
👋 Personal Touch: Displays your name and design philosophy in a minimal, well-spaced, and visually appealing layout.  
📱 Contact Screen: Neatly presents your email, phone number, and social media handles using icons for clarity and variety.  
📇 Seamless Navigation: Utilizes Flutter's Navigator with named routes for smooth transitions between the home (portfolio) and contact screens.  
🔄 State Management: Leverages setState() for dynamic profile picture toggling, demonstrating a solid understanding of StatefulWidget.

🛠 Built With

Flutter & Dart: Core framework and programming language.  
Stateful & Stateless Widgets: For dynamic and static UI components.  
Named Routes: Modular routing for clean navigation.  
Reusable Components: Structured contact items for maintainability.

🎯 Purpose
This app was created to provide a unique, lightweight alternative to a traditional PDF CV. It enables quick contact access while offering an interactive glimpse into my design thinking process. Whether for an app store listing, CV integration, or a personal website, this portfolio app stands out as a creative representation of my skills.
